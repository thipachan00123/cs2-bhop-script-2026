## FAQ

**Will the server kick me for high speed?**  
Yes on servers with max velocity cap. Enable the speed cap option to stay under the server limit.

**Does this work on FACEIT anti-cheat?**  
No — FACEIT's kernel driver detects the auto-spacebar pattern. Use on Valve servers only.
